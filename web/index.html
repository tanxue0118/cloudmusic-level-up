怎么登录

        
登录在你自己的电脑上完成，不经过服务器，避免网易云风控

        
    
          
  1. 打开电脑上的文件夹 D:\服务器
    2. 
          
  2. 双击运行 登录网易云.bat
    3. 
          
  3. 在弹出的窗口里登录网易云（扫码 / 账号密码 / 短信均可）
    4. 
          
  4. 登录成功后工具会自动同步，回到本页点「刷新状态」即可
    5. 
        

        

          
登录态（cookie）长期有效，通常可用数周到数月。失效后重新运行一次工具即可。
